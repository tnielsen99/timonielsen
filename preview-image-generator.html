How to Create Your Social Preview Image:

  1. Take a screenshot:
    • Windows: Press Win + Shift + S, then drag to select just the preview box above (the grey rectangle)
    • Mac: Press Cmd + Shift + 4, then drag to select the preview box
    • Or use browser DevTools: Right-click the preview box → Inspect → Take a screenshot of the element
  2. Save the screenshot as image-sharing.jpg
  3. Replace the file at /Images/image-sharing.jpg with your new screenshot
  4. Clear social media caches:
    • Facebook: developers.facebook.com/tools/debug/
    • LinkedIn: linkedin.com/post-inspector/
    • WhatsApp: Wait 7-30 days or try the debuggers above first

Note: The preview box above is exactly 1200x630px - the optimal size for social media previews. You can edit the text/colors in this HTML file if you want to customize it further!
